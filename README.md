# 📊 Titan Company Ltd. Financial Statement Analysis (FY2021–FY2025)

## Overview

This project analyzes the financial performance of Titan Company Ltd. over five financial years (FY2021–FY2025) using Microsoft Excel and Power BI.

The objective was to understand the company's growth, profitability, financial position, and cash flow trends while building an interactive dashboard for financial analysis.

---

## Project Objectives

- Analyze five years of financial statements.
- Evaluate revenue and profitability trends.
- Study changes in assets and liabilities.
- Analyze cash flow performance.
- Calculate important financial ratios.
- Build an interactive Power BI dashboard for visualization.

---

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- Titan Company Annual Reports (FY2021–FY2025)

## Key Insights

- Revenue increased consistently between FY2021 and FY2025.
- Profit after Tax showed significant improvement over the analysis period.
- Total assets expanded steadily, reflecting business growth.
- ROE remained strong, indicating efficient utilization of shareholders' equity.
- Operating cash flow remained positive in most years, demonstrating healthy business operations.
